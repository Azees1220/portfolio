Animated portfolio for Azees (Azees1220)

This repository now contains a professional, animated single-page portfolio website.

Files added:
- index.html — main landing page
- styles.css — styling and animations
- script.js — small interactions (typing effect, smooth scroll)

Deployment:
- The site is static and can be hosted on GitHub Pages or Vercel.
- To serve from GitHub Pages, go to the repository Settings -> Pages and set the source to the main branch (root).

Customize:
- Update the hero text, contact email, and project tiles in index.html to match your current projects and links.
- You can replace the simple typed animation with a library like TypeIt or Typed.js if you prefer.
